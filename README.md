# 伝令 MESSENGER '85 — 保守メモ

一気に言われたことを覚えて、別のことをしながらも覚えておく力（記憶スパン）を毎日伸ばすゲーム。
このリポジトリでのやり取りは、常に日本語で行ってください。

- アプリの URL: https://yutatasaki.github.io/denrei/
- アプリ本体: このリポジトリの `index.html` 1 ファイル。`git push` すると 1〜2 分で反映される。
- ホーム画面用: `manifest.json` と `icons/`（アイコン）。
- 外部の API やサーバーは使わない。読み上げはブラウザの機能（Web Speech API）、効果音はプログラムで作る。

## 記録（遊んだデータ）と同期

- 記録は端末のブラウザの中（localStorage、名前 `denrei.v1`）にある。
- **同期（kotoba と同じしくみ）**：非公開リポジトリ `yutaTasaki/denrei-data` の `state.json` に置き、PC とスマホでそろえる。
  - RECORD →「PC とスマホの同期」に GitHub トークンを入れて［トークンを保存］。トークンは端末にだけ保存され、書き出しには入らない。
  - トークンの作り方：GitHub → Settings → Developer settings → Fine-grained tokens。kotoba のトークンを編集して Repository access に `denrei-data` を足せば、同じトークンが使える。Permissions の Contents は Read and write。
  - 同期するとき：開いたとき・アプリに戻ったとき・記録が変わったとき（2〜3秒後）・［今すぐ同期］。問題の途中は待つ。
  - 片方だけで遊んだ → 新しい方にそろう。まっさらな端末は取るだけ（送らない）。
  - 両方で遊んでいた → **届けた件数が多い方** を残す。もう片方は `denrei-data/conflicts/` に保存（消えない）。
  - ファイルから読み込んだ記録は、本人が選んだものとして同期先より優先する。
  - denrei-data の履歴（コミット）に、前の記録が全部残る。
- **RECORD 画面の「記録を書き出す」** でファイル（`denrei-日付.json`）にもできる。**「記録を読み込む」** で戻せる。古い版の記録も読める。

## スマホで遊ぶ

1. Safari（iPhone）か Chrome（Android）で上の URL を開く。
2. 共有ボタン →「ホーム画面に追加」で、アイコンから開ける。
3. 新しい版にしたいときは、開き直す（すぐ変わらなければ、アプリを閉じてもう一度）。

## 困ったとき

| 症状 | 対処 |
|---|---|
| 声が出ない | 端末の消音を切る。日本語の声が無い端末では、指示が文字で出る。 |
| 効果音・雑音が出ない | 右上の ♪ が 🔇 になっていないか。 |
| 記録が消えた | 同期していれば、トークンを入れ直すと戻る。していなければ RECORD →「記録を読み込む」で、書き出したファイルを選ぶ。 |
| ホームに「⚠ 同期できていない」 | RECORD の同期の欄の文を読む。401・403 = トークンが切れた／denrei-data が許可に入っていない → トークンを直して入れ直す。404 = Repository access に denrei-data が無い。通信できない = 電波の良い所で［今すぐ同期］。 |
| 記録が思ったのとちがう端末の方になった | `denrei-data/conflicts/` に、残らなかった方の記録がある。そのファイルを落として RECORD →「記録を読み込む」。 |
| プレッシャーがきつい | 右上のボタンで「😌 静か」にする。 |

## 直すとき

- 直したら、機械の確かめ（Node のテスト）を通してから push する。
- コミットの見出しは `v番号 何を変えたか` の形（日本語）。
